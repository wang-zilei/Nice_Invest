## 二、各 Agent 输出摘要

### 1. 基本面分析师（置信度 0.8，输出 1832 字符）

**核心结论：基本面稳健但增长动能减弱**

| 维度 | 评分/数据 | 说明 |
|------|----------|------|
| 盈利能力 | 7.5/10 | ROE 稳定在 10%+，净利率趋势向好 |
| 成长性 | 5.0/10 | 营收 3 年 CAGR 仅 2.37%，2023 年同比 -8.45% |
| 偿债能力 | 6.5/10 | 高杠杆（92%+）但不良率 1.06%、拨备覆盖率 280%+ |
| 运营效率 | 7.0/10 | 成本收入比 <30%，优秀；资产周转率逐年略降 |
| **综合** | **6.5/10** | |

关键风险：净利润增速远超营收增速（依赖拨备释放），增长模式不可持续。

### 2. 技术面分析师（置信度 0.8，输出 3277 字符）

**核心结论：长期偏多但短期调整，等待方向选择**

| 维度 | 特征 |
|------|------|
| 长期趋势 | 2023 年底至 2024 年底上升通道，底部从 8.99 抬升至 11.14 |
| 中期趋势 | 2025 年以来高位回落，12.63 → 12.00，低点下探至 10.48 |
| 短期趋势 | 近 8 日从 10.89 反弹至 11.39，止跌企稳 |
| 量价关系 | 上涨放量、下跌缩量，配合正常，无背离 |
| 波动率 | 从 24.6%（2023）→ 5.6%（近 8 日），显著收窄 |

关键价位：支撑 10.48/10.89，压力 11.50/12.00。

### 3. 估值分析师（置信度 0.8，输出 2985 字符）

**核心结论：估值处于历史低位，但"便宜"不等于"低估"**

| 指标 | 当前值 | 历史分位 |
|------|--------|---------|
| PE(TTM) | ~5.0x | 近 5 年 20-30% 分位 |
| PB | ~0.55-0.60x | 近 5 年 15-25% 分位 |
| PEG | ~1.0 | 合理区间 |
| 股息率 | ~6%-7% | 有吸引力 |

核心判断：低估值更多反映市场对行业前景（净息差收窄）的谨慎预期，非明显低估机会。

### 4. 新闻舆情分析师（置信度 0.65，输出 1952 字符）

**核心结论：中性偏谨慎，缺乏正面催化剂**

## 三、Summary 投资摘要

**投资倾向：中性**

**3 条核心理由**：
1. 估值具备安全边际（PE ~5x，PB ~0.55x），股息率 6-7% 有吸引力
2. 基本面稳健但增长动能减弱，营收增长乏力（2023 年同比 -8.45%），利润增长依赖不可持续的拨备释放
3. 技术面处于调整末端，近期止跌企稳但能否突破 11.50-12.00 压力位是关键

**关键风险**：营收增长拐点 / 盈利可持续性 / 净息差持续收窄 / 高杠杆

## 四、数据来源与限制

| Agent | 主要数据源 | 数据质量 |
|-------|-----------|---------|
| 基本面 | Tushare 财报接口（部分成功）+ LLM 补充 | 中等 — 部分数值为估算 |
| 技术面 | Tushare `daily` 接口（稳定可用） | **高** — 真实 OHLCV 数据 |
| 估值 | Tushare `stock_basic`（频率限制）+ LLM 补充 | 中等 — 关键指标参考值 |
| 新闻舆情 | LLM 知识兜底（新闻接口权限不足） | 低 — 无实时新闻 |

**已知 Tushare 限制**：
- `stock_basic`：免费用户 1次/分钟，高频调用触发限流
- `news` / `gs_news`：需积分 >= 120，当前权限不足

## 五、修复记录

本次测试前共修复 5 个 Bug（详见 [tests/README.md](README.md)）：

1. DeepSeek API 调用了 `ChatAnthropic` 协议（实际为 OpenAI 兼容协议）
2. `valuation.py` 装饰器语法错误导致导入崩溃
3. 全量分析路由将 `full` 直接映射到 Summary，跳过所有 Agent
4. ReAct 循环中多 tool_call 场景的 AIMessage 顺序违反 API 协议
5. 并行 Agent 返回 `**state` 导致状态冲突和 `agent_results` 翻倍
